description: Use for implementing features in Next.js App Router with TypeScript and Tailwind.
---

Workflow:
1. Inspect existing route/component/data patterns.
2. Reuse conventions before introducing new abstractions.
3. Keep data fetching close to the server boundary.
4. Extract reusable logic only when duplication is real.
5. Finish by checking:
   - types
   - lint
   - build
   - obvious edge cases
